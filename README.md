# florenswitcher
Floren Switcher script for SAMP. Change weather or time. FOSS


Что делает?

Данный скрипт облегчает вашу жизнь. Меняет погоду в игре и времени

Активация скрипта - нажать на кнопку Z.


Установка

1. Скачать скрипт
2. Перенести lua скрипт в папку с игрой
3. Запустить и нажать на Z
